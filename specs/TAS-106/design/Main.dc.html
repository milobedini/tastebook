One heading, two sections. “Your account” is the page’s Display XL title, with the screen’s one squiggle under “account”. Each setting gets a Title section heading (“Name”, “Units”), so download everything (TAS-133) and delete your account (TAS-134) slot in later as sections of their own. The spec drew no heading over the name; I added “Name” so both sections read the same way.

The name works as on the name page: the same field, 50-character limit and errors in the field’s own line. “Save name” is the screen’s one peach button. The help line is the name page’s own sentence, since the name is the one shown on recipes.

A failed save is a toast, not a Banner, as the spec says: the page is already open and working, and the typed name stays in the field, so pressing Save name again is the retry. Success is a toast too (“Name saved”), and the top bar’s button takes the new name at once.

The household isn’t mentioned. Changing your name leaves “Milo’s household” as it is; renaming a household belongs to the household page (TAS-108).
