The address is in bold and wraps anywhere, so a long one never pushes the page sideways (see the 320 px board).

Code: numeric keyboard, one-time-code autofill (phones offer the code from the email or message), at most 6 characters.

Wrong code and run out keep the code in the field, so it can be corrected rather than retyped; the error goes as soon as Sign in is pressed again.

Use a different email is secondary: it goes back, it doesn’t finish. At 390 px it wraps under Sign in, which keeps room for “Signing in…”.

No “send another code” button. The spec sends people back through step 1 for a new code; TAS-104 sets the limits a resend button would need.
