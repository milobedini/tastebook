The section is “Invite someone”, the field “Invite link”. The spec named both the heading and the field “Invite link”, which reads twice in a row; I renamed the heading so it says what the section is for, and kept the field’s label, which the tests find it by. The copy otherwise is the spec’s.

Save name stays the one peach button (Rules: one peach button per screen). Make invite link, Make a new link and Copy link are secondary, each with its icon (Link, Copy); Cancel link is a ghost button, so the quieter way out sits beside the thing you came for. The danger colour appears only in the dialog, on the button that does it.

The live link is a read-only Input in a Field, the whole address in it and cut off at the field’s edge on a phone; the help line gives the last day. Focusing the field selects the whole address, so “Select it and copy it yourself” is one tap and a Copy. The date is day and month only, as the spec assumes.

Cancel asks first, in ConfirmDialog (its own board), whose way out now says “Keep link”. Focus starts on Keep link, so Enter never cancels by accident. After cancelling, the section goes back to no link with the toast “Link cancelled” and focus on Make invite link, so it isn’t lost with the button that was pressed.

An expired link says so in words, in Body, not a butter Note or a warning Banner: it’s a plain fact about time with one way on, and the section’s single button is that way. The expired address isn’t shown, as it can’t be used.

Failures are toasts and change nothing, as on the name: the section stays as it was, so pressing the same button again is the retry. A link made by another member at the same moment comes back as the same link (the spec’s one live link), so there’s no clash to draw.
